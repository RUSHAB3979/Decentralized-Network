# Provider agent dependencies.
#
# This list is deliberately short, and it is a security boundary as much as a
# build input. The agent runs on a provider's own machine — a stranger's gaming
# PC — so anything listed here is something we have shipped onto hardware we do
# not control.
#
# In particular: no database driver, ever. The agent talks to the orchestrator
# over HTTP and nothing else. If psycopg shows up in this file, the design has
# gone wrong upstream of the file.
#
# Pinned exactly (==) so every provider machine resolves the same tree. Bumps
# come through Dependabot.

# Control plane and Ollama, both over HTTP.
httpx==0.28.1
python-dotenv==1.2.4

# System tray UI. pystray is the whole reason pillow is here - it takes icons
# as PIL images, and drawing them in code avoids shipping an .ico as a
# PyInstaller data file. Both are pure presentation: neither one gets the agent
# any reach it did not already have, which is the test that matters for this
# file.
pystray==0.19.5
pillow==12.3.0

# Desktop dashboard. pywebview draws the window with Edge WebView2, which is
# already on every supported Windows machine, so this ships no browser engine
# and no HTTP server - the window loads a file from disk. It does pull in
# pythonnet to reach WinForms, which is the largest single addition to the
# agent's footprint in this file and the one worth re-justifying if it grows.
#
# Against the test that governs this file: the page can only reach the process
# through the js_api object in agent/ui/window.py. That object exposes reading
# a telemetry snapshot and toggling whether this node accepts work. Rendering
# gains the agent no reach it did not already have.
pywebview==6.2.1
